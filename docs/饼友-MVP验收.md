## 可用功能

- [x] 个人主页一键加入饼友；侧栏输入 UID／主页链接预览并加入。
- [x] 本地备注、分组、置顶、昵称／备注搜索与移除。
- [x] 仅在原站昵称旁显示轻量绿色标记，备注以悬停提示呈现。
- [x] 主题／回帖动态，用户／分组／类型筛选及原帖链接。
- [x] 全部／单人手动刷新、进度、停止、更早分页、5 分钟最新页缓存。
- [x] JSON 备份导出、导入预览、默认保留冲突与显式覆盖。
- [x] 缓存清理与上限、浏览器重启后的名单持久化。
- [x] 360px、480px 布局与深浅色主题。

## 关键行为判定

- [x] UID 主键；改名保留原有备注。
- [x] 回帖行为人取主页 UID，不能取条目头像的主题作者 UID。
- [x] 回复数只取评论图标字段，数字昵称不覆盖计数。
- [x] 失败保留上一次成功数据；主题成功而回帖失败显示部分更新。
- [x] 取消后不提交迟到结果；删除用户后旧任务不能重新创建。
- [x] 合并按稳定 ID 去重；历史页不标“新发现”，不延长最新页缓存。
- [x] 429 遵守冷却时间，冷却中不会再次请求。
- [x] 源码仅申请 storage、sidePanel 和 linux.sb 站点权限。
- [x] 主题详情的饼友标记可用；列表与详情都有相对时间。

## 未完成的现场验证与影响

- [ ] **登录账号和受限评论**：测试使用访客页面；需要用户在日常浏览器加载后验证。当前支持公开用户页摘要，未验证多账号隔离。缓存可能来自之前的浏览会话，切换账号后可主动清理。
- [ ] **精确创建时间字段**：原站详情没有对应 Unix 时间戳，不能逐秒确认列表字段语义。UI 将其标为「原站」，不声称是精确上线时间。最初要求的精确创建时间对照仍未通过。
- [ ] **原站发帖／点赞流程**：未执行会改变站点内容的动作；页面增强只新增自身按钮与徽标。
- [ ] **日常浏览器原生侧栏外壳**：已验证扩展页面与 360–480px 渲染，正式浏览器工具栏点击、原生侧栏开启建议首次安装时检查。

## 用户第一次加载的最短验收

1. 按 [README](../README.md) 加载 `dist/`，刷新烧饼站页面。
2. 加入一个熟悉的用户，保存一条备注，打开侧栏点击刷新。
3. 检查主题和回帖作者是否正确，原帖能否打开；重开侧栏确认备注还在。

如果登录态或侧栏出现差异，提供错误文字、页面 URL 和浏览器版本即可据此修复。

## 0.1.1 页面集成修正

- 修复所有用户主页链接都被标记的问题。现在只标记个人卡片昵称、列表作者昵称和帖子作者昵称，主题／回帖／收藏导航与右侧菜单不加标记。
- 昵称旁只显示绿色圆点和「饼友」，无按钮色块，备注保留在悬停提示中。
- 「加入饼友／已加入饼友」排列在个人卡片操作区，实际宽高、字号、圆角和左右边距对齐原站私信／屏蔽按钮。
- 页面入口、侧栏、图标统一为低饱和度绿色，覆盖浅色与深色。
- 在采用原站 DOM 与按钮 CSS 的复现页面中，三按钮均为 220×37px，缩窄后均为 190×37px；添加前后及翻页保持一致。
- 真实访客个人页已确认导航不再误标。登录态私信／屏蔽按钮的几何对齐由复现页面验证，没有操作站点私信或屏蔽。
