# 饼友 v0.1.1 · 首个公开 MVP

为烧饼站 linux.sb 提供本地饼友名单、备注和动态聚合，适用于 Chrome / Edge 120 及以上版本。

## 主要功能

- 用户主页一键加入饼友，或输入 UID / 主页链接添加。
- 本地备注、分组、置顶和搜索。
- 聚合主题与回帖摘要，支持筛选、手动刷新、停止和更早分页。
- JSON 名单备份、导入预览和冲突处理。
- 昵称旁的轻量绿色标记与悬停备注。
- 低饱和度绿色界面，适配系统深浅色主题。

## 0.1.1 页面改进

- 仅标记昵称，不再给主题、回帖等导航链接重复添加「饼友」。
- 「加入饼友」按钮尺寸对齐原站「私信 TA」「屏蔽 TA」按钮。
- 页面入口、侧栏和图标统一为柔和绿色。

## 下载安装

1. 下载本页附件 **sb-friends-0.1.1-chrome-edge.zip**，解压到固定文件夹。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式。
3. 点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的文件夹。
4. 刷新烧饼站页面，加入一位饼友，打开侧栏并点击刷新。

附件已包含构建结果，无需 Node.js。GitHub 自动生成的 Source code 包是源码，不能直接加载。

已安装本地版本的用户：先导出名单备份，将新包覆盖到原安装目录，重新加载扩展，再刷新烧饼站网页。

## 数据与当前限制

- 名单和缓存存储在浏览器本地，无云同步、遥测或自动轮询。
- 取数需要保留已打开的烧饼站标签页；遇到登录验证或限流会停止。
- 数据按浏览器配置保存，未按站点账号隔离。切换账号后可主动清理动态缓存。
- 动态时间标注「原站」，不表示最后在线时间。
- 登录账号受限内容、多账号切换及日常浏览器原生侧栏外壳仍需现场验证。

## 验证
